# 🐍 POO — Programação Orientada a Objetos em Python
 
> *"No mundo da POO, tudo é um objeto... até o seu café ☕."*
 
Repositório com as aulas e provas práticas da disciplina de **Programação Orientada a Objetos** usando **Python**.
Aqui estão os exercícios, exemplos e atividades desenvolvidos ao longo do semestre, aprendendo a pensar em **objetos** em vez de só em linhas de código soltas.
 
---
 
## 🎯 Objetivo
 
Aprender e praticar os conceitos de POO de um jeito **prático e divertido**, construindo pequenos sistemas que imitam o mundo real (e alguns mundos de fantasia também 🧙‍♂️).
 
---
 
## 🧱 Os 4 Pilares da POO
 
| Pilar | Em uma frase | Analogia |
|-------|--------------|----------|
| 🔒 **Encapsulamento** | Esconder os detalhes internos e expor só o necessário | O controle remoto: você aperta o botão, não mexe nos circuitos |
| 🎭 **Abstração** | Focar no que importa e ignorar o resto | Dirigir um carro sem saber como funciona o motor |
| 🧬 **Herança** | Uma classe filha herda características da classe mãe | Você herdou os olhos da sua mãe 👀 |
| 🦎 **Polimorfismo** | O mesmo comando, comportamentos diferentes | "Fale!" → o cachorro late, o gato mia |
 
---
 
## 📚 Glossário rápido
 
- **Classe** → a *planta* da casa 📐
- **Objeto** → a *casa* construída 🏠
- **Atributo** → as características (cor, tamanho, nome)
- **Método** → as ações (abrir porta, acender luz)
- **`self`** → o próprio objeto falando de si mesmo 🪞
- **`__init__`** → o construtor, chamado quando o objeto "nasce" 🐣

## 🚀 Como executar
 
1. Clone o repositório:
```bash
   git clone https://github.com/Auggusti0G/POO-.git
```
2. Entre na pasta da aula ou prova desejada:
```bash
   cd POO-/Aula01
```
3. Rode o arquivo Python:
```bash
   python nome_do_arquivo.py
```
 
> Requisito: **Python 3.8+** instalado.
